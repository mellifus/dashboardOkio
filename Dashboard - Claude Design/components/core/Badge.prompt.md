Small status/category labels — workflow status pills, VIP marker, AI confidence tag.

```jsx
<Badge tone="accent">Listo para aprobar</Badge>
<Badge tone="accent" uppercase>VIP</Badge>
<Badge tone="warning">Requiere revisión inmediata</Badge>
```

Use `uppercase` for tight all-caps tags like "VIP" or "NUEVO". Use the default (sentence case) form for longer workflow-status text like "Esperando aprobación" or "Resuelto".
