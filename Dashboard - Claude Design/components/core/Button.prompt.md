Solid, outlined and text buttons for primary CTAs, secondary actions and inline actions.

```jsx
<Button variant="primary" size="lg" withShadow>+ Nuevo turno</Button>
<Button variant="secondary">Editar antes</Button>
<Button variant="ghost" size="sm">Omitir</Button>
```

Variants: `primary` (solid accent, used for the one main action per screen — "Aprobar y enviar", "+ Nuevo turno"), `secondary` (white with border, paired actions like "Mensaje" / "Editar antes"), `ghost` (no border, low-emphasis inline actions). `withShadow` adds the subtle accent shadow used on page-level CTAs, not on inline row actions.
