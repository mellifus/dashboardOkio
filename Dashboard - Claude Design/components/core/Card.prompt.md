General-purpose bordered, rounded container — the base for panels, KPI tiles, quotation/appointment sub-cards and the AI Copilot card.

```jsx
<Card tone="accent"><strong>Copiloto IA</strong> …</Card>
<Card tone="warning">Protocolo de hinchazón post-relleno …</Card>
```

`default` gets the standard card shadow; the tinted tones (`accent`, `warning`, `subtle`) are flat, no shadow — used for nested cards inside a workspace.
